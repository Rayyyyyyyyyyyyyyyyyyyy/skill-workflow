# claude-cloud-portability

## 原始想法

把此 repo 的工作入口、流程交接文件及使用到的 Skills/Agent Roles 整理成可由 Claude 雲端 session 從 GitHub clone 後使用、不依賴原電腦個人目錄的版本。保留 grill-me/grill-with-docs 討論能力與既有 Proof/安全規則，明示本機狀態無法直接跨機恢復。

進度與接續：在集合根目錄執行 `python3 workbench.py status claude-cloud-portability`。
正式狀態與版本保存在 `.workflow/`；成果預設放 `workspace/`。

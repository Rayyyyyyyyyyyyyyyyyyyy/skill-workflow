## 需求

- R1 燈箱開啟：縮圖放大到燈箱位置；關閉時縮回該照片的縮圖。若關閉時該照片縮圖不在畫面或未渲染，改用淡出。
- R2 燈箱左右切換（滑動放開後、方向鍵、按鈕）：舊照片往切換方向滑出、新照片滑入。`lightbox-swipe.js` 判斷邏輯不變。
- R3 分類／來源切換：照片格整體淡出淡入，新卡片沿用既有 `gin` 浮入；不做逐卡位移。
- R4 收藏：加入收藏時圖示輕彈約 200ms；取消收藏無動畫。
- R5 主題切換：整頁交叉淡入淡出約 250ms。
- R6 全部動畫低調快速（約 150–300ms，以位移與透明度為主）。
- R7 技術：View Transitions API + CSS 優先；需要新增套件（含 devDependency）時先停下並列出套件、用途、替代做法交使用者決定（2026-11-01 使用者補充）；不支援 View Transitions 的瀏覽器直接切換，功能不變。
- R8 `prefers-reduced-motion: reduce` 時新動畫全部關閉（含 View Transitions）。
- R10（2026-11-01 使用者追加）燈箱加「旋轉 90°」按鈕：只影響當下觀看、不改資料；切換或關閉燈箱後重置；旋轉後照片仍完整放進可用區域（含手機）；按鈕有 aria-label、鍵盤可用；旋轉過渡沿用低調時長並尊重減少動態。起因：部分 Pinterest 原圖本身內容是側的（例：pinterest_1015069203508638797_2876460975.jpg），程式無法自動判斷。
- R10 修正（第三輪審查必修）：訪客暫時旋轉在照片 id 改變時必須真的歸零（a→b→a 回到 a 為 0°；單張清單切回自己也歸零）。
- R11（2026-11-01 使用者追加）管理員永久旋轉：管理員在燈箱按旋轉即存雲端，所有人的格子（瀑布流比例跟著交換）與燈箱都依此方向顯示；訪客仍保留不存檔的暫時旋轉（疊加在雲端方向之上）。雲端旋轉讀不到時照原方向顯示、不擋相簿。寫入沿用 gallery-delete 的安全模式：新 Supabase migration（公開只讀 id+方向、瀏覽器不可寫、service_role 寫）與新 Edge Function（verify_jwt、實際 session 與 gallery_admins 檢查、id 必須存在於 gallery_images 或 manifest 規則、方向限 0–3）。本版只交付程式與 migration 檔，不部署、不寫入 Supabase；部署需使用者另行授權。
- R12（2026-11-02 使用者修改 R11 互動）管理員旋轉分兩段：按旋轉只在本地轉（不打 API）；若淨方向與雲端不同，在關閉燈箱（關閉鈕、Esc、點背景）或換張（按鈕、方向鍵、滑動）時跳出確認視窗「儲存／不儲存／取消」。儲存→呼叫 gallery-rotate，成功後繼續原動作；失敗→留在這張、保留轉好的方向、顯示錯誤，可重試或改選不儲存。不儲存→還原雲端方向後繼續原動作。取消→留在這張。淨方向回到雲端方向時不詢問。訪客維持暫時旋轉、不詢問。
- R12 修正（第六輪審查必修）：儲存成功後繼續關閉／換張時，雲端新方向必須已 commit 到 DOM，再執行轉場（不得先跳回舊方向或在轉場中插值旋轉）。
- R13（2026-11-02 使用者追加）格子卡片按鈕位置：收藏在照片右上角；管理員的垃圾桶按鈕在照片左上角（aae1748 移除了卡片刪除鈕，恢復為只有管理員可見，開既有刪除確認對話框）。
- R14（2026-11-02 使用者追加）頁面提示（app.jsx 的 .admin-notice，例如「已刪除 1 張照片。」）顯示 3 秒後自動消失；新訊息重新計時；保留 role=status。
- R15（2026-11-02 使用者追加）效能：卡片 memo 不得因 removeImage 等每次 render 新建的 callback 而失效（訪客與管理員皆然）。
- R16（2026-11-02 使用者追加）錯誤類提示停留較久：成功／一般提示維持 3 秒；錯誤提示（頁面 .admin-notice 的錯誤訊息與燈箱 role=alert 錯誤，如旋轉／儲存失敗）停留 8 秒；新訊息重計時；可手動關閉者保留關閉鈕。
- R9 既有行為不退化：鍵盤操作與焦點還原、燈箱焦點陷阱、Escape 關閉、雙指縮放時不翻頁、刪除照片流程、分頁與瀑布流。

## 驗收

- `npm run build` 成功；`python -m unittest discover -s tests -v` 通過（winter 現有測試方式，以其 AGENTS.md 為準）。
- 新增的非平凡邏輯（例如 View Transition 包裝與不支援／減少動態退回、決定關閉時是否縮回）有可執行測試，或說明為何無法在非瀏覽器環境測試。
- 逐項 R1–R9 對應改動位置；未驗證項（實際動畫觀感、各瀏覽器實測）明列。
- 成果以 commit 留在 `ft/ux-motion`，附交付說明 `docs/ux-motion.md`（改動、使用方式、限制、未驗證項）。

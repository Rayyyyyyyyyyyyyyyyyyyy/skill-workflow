# winter-ux-motion 討論紀錄

方法：grilling（分輪決策樹）。原始想法見 PROJECT.md。

## 已知事實（2026-11-01 查證）

- winter 現有動畫：卡片進場 `gin`、圖片載入淡入、燈箱 `gfade` 0.2s、載入點 `gpulse`、hover 背景過渡；已有 `prefers-reduced-motion` 全關規則（`src/styles.css`）。
- 燈箱滑動（`src/lightbox-swipe.js`）只在手指放開時判斷方向翻頁，沒有跟手位移。
- 主題切換是 `useGalleryPreferences.toggleTheme` 直接換 `data-gal-theme`。
- winter 工作區有使用者未提交修改（images.json、縮圖刪除等），任何工作都須保留。

## 第 1 輪決策（使用者回答）

- Q1 目的：(a) 操作連貫感——看得出圖片從哪來、往哪去。
- Q2 範圍：1 燈箱開關縮放、2 燈箱左右切換、3 分類／來源切換轉場、4 收藏按鈕回饋、5 主題切換過渡。（6 對話框進場不做）
- Q3 強度：低調快速（約 150–300ms，位移與透明度為主）。
- Q4 交付：winter 本機 branch，不部署；動畫成效由使用者人工判斷，不做瀏覽器自動檢查。

## 第 2 輪決策（使用者回答）

- Q5 技術：View Transitions API + CSS，不新增套件；不支援的瀏覽器直接切換、功能不變。
- Q6 燈箱切換：只做放開後的滑出／滑入動畫，滑動判斷邏輯不變；方向鍵切換同樣套用。跟手拖曳列為候選。
- Q7 分類／來源切換：整格淡出淡入，新卡片沿用 `gin` 浮入；不做逐卡位移。
- Q8 收藏：加入時圖示輕彈約 200ms，取消時無動畫。
- Q9 主題：整頁交叉淡入淡出約 250ms，不做圓形擴散。
- Q10 減少動態：沿用現有規則，新動畫全部關閉。

## 第 3 輪（共識確認，待使用者確認）

- 預設：燈箱關閉時若當前照片的縮圖不在畫面中或尚未渲染，改用現有淡出、不做縮回。
- 候選（不在本版）：跟手拖曳、對話框進場動畫。

# Humanizer

## Workflow

1. Identify the audience, channel, desired tone, and constraints from the prompt or surrounding artifact.
2. Preserve facts, intent, names, numbers, citations, and commitments. Do not add claims that were not present unless explicitly asked.
3. Remove common AI tells: generic openings, over-balanced phrasing, padded transitions, exaggerated certainty, repeated sentence rhythm, and empty adjectives.
4. Replace abstract language with concrete phrasing, natural contractions where appropriate, and varied sentence length.
5. Keep the user's voice when there is enough sample text. If no voice sample exists, choose a plain, confident, low-drama style.
6. For high-stakes content, separate style edits from factual edits and flag any uncertain claims.

## Quality Bar

- Prefer one strong rewrite over many mediocre variants unless the user asks for options.
- Keep the result easy to scan and suited to the medium.
- Avoid sounding deliberately casual when the context is formal.
- If the source is already good, make a light pass and say what changed.
